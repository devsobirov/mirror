# Сервисы

- Сервис, который пишет в больше чем одну таблицу, оборачивает запись в `DB::transaction(...)`.
- На вход сервис получает уже провалидированный массив или DTO. `request()` и `auth()` внутри сервиса не читаются, пользователь передаётся параметром.
  Исключение — существующий `OfferService::save` (`auth()->id()`), его не тиражировать.
- `Log::info` на каждом вызове не добавлять. Логировать ошибки и важные бизнес-события.
- Подпапки по домену: `Services/Finance/`, `Services/Offers/`…
