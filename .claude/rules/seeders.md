# Сидеры и фабрики

- Демо-данные живут только в `database/seeders/Demo/*`. Точка входа — `DemoSeeder`; он отказывается работать в production.
  Новый демо-сидер вызывается только из `DemoSeeder`.
- Демо-сидеры детерминированные: случайные значения берутся только из `mt_rand` после `mt_srand(<константа>)`, без `rand()`, `Faker` без seed и `now()` в данных.
- Расчёт сумм в `DemoOrdersSeeder` совпадает с формой заказа (см. `.claude/rules/offer-calc.md`).
- Реальных пользователей не трогать: демо-пользователей upsert'ить по телефону.
- После правки прогнать `DemoSeeder` и открыть затронутые страницы.
- Старые сидеры в корне `database/seeders/` не расширять.
