# FormRequest

- В `authorize()` проверяется роль: `auth()->check() && auth()->user()->isWorker()` для рабочих разделов, `isAdmin()` для админки.
- Нормализация входа (телефоны, вложенные поля, значения по умолчанию) делается в `prepareForValidation()`.
- Любое поле, которое подставляется в `merge()` и должно попасть в БД, обязано быть в `rules()`.
  Иначе оно выпадет из `validated()` (пример: `status` в `Finance/DebtCreateRequest`).
- Значения enum проверяются через `Rule::enum(…)` или `in:` по `Enum::cases()`, а не списком литералов.
- Пользовательские сообщения пишутся на узбекском (латиница).
- Новый запрос кладётся в подпапку домена: `Offers/`, `Finance/`, `Service/`, `Users/`.
