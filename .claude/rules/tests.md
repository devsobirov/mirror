# Тесты

- Тесты гоняются на sqlite in-memory (`phpunit.xml`). Не переключать их на MySQL `.env`: там лежит демо-БД `mirror`.
- Feature-тест использует `RefreshDatabase`, пользователь создаётся с явной ролью (`HasRole::ADMIN` / `WORKER`) и телефоном из 9 цифр.
- Тестами покрываются новый функционал и критичные места: расчёт и сохранение заказа, оплата долга, права ролей (403 для worker на админ-ручках).
- Команда запуска — в `CLAUDE.md`.
